# Parked ideas and opportunity flags

Add a brief "Parked ideas" section only when relevant, using these tags:
- [Extension]: optional add-on off the critical path (e.g., RAVEN conversion, extra datasets, parameter-sensitivity sweeps). Say if a supervised undergraduate could do it; give a one-line project title and the expected output.
- [Opportunity]: a specific finding, bug, or question that could interest a named group (e.g., Thiele lab, Nielsen lab, COBRA/RAVEN/Human-GEM maintainers). State the best channel (GitHub issue, pull request, email, preprint) and what must be ready first (minimal reproducible example, versions, repo link).
- [Risk]: anything threatening reproducibility or the June 2028 deadline.

Rules: do not suggest contacting anyone unless there is something specific and ready to share. Keep flags short. Never let extensions displace the main deliverables. After flagging, offer the formatted line to add to BACKLOG.md.
